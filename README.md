# Blinkit Sales Analysis – Power BI Dashboard

## 📊 Project Overview

This project presents an interactive **Blinkit Sales Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyses sales performance across different outlet types, outlet sizes, outlet location tiers, item types, and item fat-content categories. It provides both high-level business KPIs and detailed product-level insights.

---
## 📂 Dataset

### Kaggle – BlinkIT Grocery Sales Dataset

The dataset used for this project is the **BlinkIT Grocery Sales Dataset**, which is available on Kaggle.

🔗 **[Dataset Link – Kaggle](https://www.kaggle.com/datasets/architgoel29/blinkit-dashboard)**


---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyse overall sales performance.
- Identify the major contributors to total sales.
- Compare sales across different outlet types.
- Analyse sales by outlet size and location tier.
- Identify the highest-selling product categories.
- Compare sales based on item fat content.
- Analyse average ratings across different outlet categories.
- Identify products with high visibility.
- Provide interactive business insights using Power BI.

## 📌 Dashboard Sections

### 1. Executive Sales Dashboard

The Executive Sales Dashboard provides a high-level overview of Blinkit's sales performance.

It includes:

- Total Sales
- Average Rating
- Total Products
- Number of Outlets
- Average Visibility
- Total Sales by Outlet Size
- Total Sales by Outlet Establishment Year
- Total Sales by Outlet Location Type
- Total Sales by Outlet Type
- Total Sales by Item Type

### 2. Product Insights Dashboard

The Product Insights Dashboard focuses on product and category-level analysis.

It includes:

- Total Sales by Item Type and Outlet Type
- Total Sales by Item Fat Content
- Outlet Size vs Average Rating
- Top 10 Products by Visibility
- Total Sales by Outlet Location Type and Item Type

### 3. Detailed Analysis using Matrix, Waterfall and Decomposition Tree

The detailed analysis section includes:

- Total Sales by Item Type using Waterfall
- Item Fat Content analysis using a Matrix
- Sales Analysis using a Decomposition Tree

The decomposition tree allows Total Sales to be analysed through multiple dimensions such as:

**Outlet Type → Outlet Size → Outlet Location Type → Item Fat Content → Item Type**

## 🔍 Key Insights

### Outlet Type

**Supermarket Type1** is the largest contributor to total sales, generating approximately **787.55K** in sales.

| Outlet Type | Total Sales |
|---|---:|
| Supermarket Type1 | 787.55K |
| Grocery Store | 151.94K |
| Supermarket Type2 | 131.48K |
| Supermarket Type3 | 130.71K |

### Outlet Size

Medium-sized outlets contribute the highest proportion of total sales.

| Outlet Size | Sales | Share |
|---|---:|---:|
| Medium | 507.9K | 42.27% |
| Small | 444.79K | 37.01% |
| High | 248.99K | 20.72% |

### Item Type

The highest-selling item categories include:

- Fruits and Vegetables – approximately 178K
- Snack Foods – approximately 175K
- Household – approximately 136K
- Frozen Foods – approximately 119K
- Dairy – approximately 101K

### Item Fat Content

Low Fat products contribute approximately **776.32K (64.6%)** of total sales, while Regular products contribute approximately **425.36K (35.4%)**.

### Location Type

Sales are distributed across Tier 1, Tier 2, and Tier 3 outlet locations, with Tier 3 contributing approximately **0.47M** in total sales.
