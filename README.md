# BlinkIT Sales Analysis – Power BI Dashboard

## 📊 Project Overview

An interactive **BlinkIT Sales Analysis Dashboard** developed using **Power BI** to analyse sales performance across products, outlet types, outlet sizes, and locations.

The project includes data cleaning and transformation using **Power Query**, data modelling, DAX, and interactive data visualisation.

---

## 🎯 Objectives

- Clean and transform the dataset using **Power Query**.
- Analyse overall sales performance and key KPIs.
- Compare sales across outlet types, sizes, and location tiers.
- Identify top-performing product categories.
- Analyse sales by item fat content.
- Explore average ratings and product visibility.
- Build an interactive Power BI dashboard for business insights.

---

## 🧹 Data Cleaning

Data cleaning and transformation were performed using **Power Query**, including:

- Changing data types
- Renaming columns
- Standardizing Item Fat Content values
- Splitting and merging Item Identifier
- Capitalizing text
- Creating conditional and custom columns
- Rounding numerical values
- Reordering columns

Detailed data-cleaning steps are documented separately in the project documentation.

## 📈 Dashboard

The Power BI dashboard consists of three main sections:

### 1. Executive Sales Dashboard

- Total Sales
- Average Rating
- Total Products
- Number of Outlets
- Average Visibility
- Sales by Outlet Size
- Sales by Outlet Type
- Sales by Location Type
- Sales by Item Type

### 2. Product Insights Dashboard

- Sales by Item Type and Outlet Type
- Sales by Item Fat Content
- Outlet Size vs Average Rating
- Top 10 Products by Visibility
- Sales by Location Type and Item Type

### 3. Detailed Analysis

Uses **Waterfall Chart, Matrix, and Decomposition Tree** for deeper analysis:

- Total Sales by Item Type – Waterfall
- Item Fat Content Analysis – Matrix
- Sales Analysis – Decomposition Tree

---

## 🔍 Key Insights

- **Supermarket Type1** is the largest contributor to total sales at approximately **787.55K**.
- **Medium-sized outlets** contribute the highest share of sales at **42.27%**.
- **Fruits and Vegetables** and **Snack Foods** are the highest-selling item categories.
- **Low Fat** products contribute **64.6%** of total sales.
- Overall **Average Rating is 3.92**.
