# 📊 Blinkit Sales Analysis using Power BI

## 📌 Overview

An interactive Business Intelligence dashboard built using **Microsoft Power BI** to analyze Blinkit's grocery sales data. The project involves data cleaning with Power Query, DAX measure creation, data modeling, and interactive dashboard development to visualize sales performance.

---

## ✨ Features

- Data Cleaning using Power Query
- Data Transformation
- DAX Measures & KPIs
- Interactive Executive Sales Dashboard
- Data Modeling
- Interactive Visualizations

---

## 📂 Dataset

**Source:** Kaggle – Blinkit Grocery Sales Dataset

**Dataset Link:**  
https://www.kaggle.com/datasets/architgoel29/blinkit-dashboard

---

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
